# CrossConvert

CrossConvert is a mobile-first progressive web app for converting equivalent fitness movements, distances, and weights. It also calculates barbell percentages and plate loading based on the user's available equipment.

The app runs entirely in the browser. Equipment and percentage settings are stored locally, and the installed PWA works offline after its first load.

## Development

```sh
npm install
npm run dev
```

## Validation

```sh
npm test
npm run lint
npm run build
```

Use `npm run preview` to serve the production build locally.
